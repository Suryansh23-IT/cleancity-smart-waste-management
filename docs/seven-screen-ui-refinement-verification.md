## Actual browser journeys

- All seven screens navigated at 1536, 1280, 768 and 390 px viewport settings without horizontal document overflow. Responsive checks are browser emulation, not physical-device certification. Viewport restored afterward.
- Greenfield Dashboard showed 24 scheduled and one unserved pickup; clicking the alert filtered to the exact bin and oversized-load reason. Studio/Dispatch shortcuts and fleet jump worked. A real browser playback run completed 24 pickups with one unserved; Dashboard showed completion and opened Analytics/forecast details.
- Cities search found Rivergate Crossing; database jump and sign-in form were reachable without using credentials or contacting Atlas. Mobile menu, Dashboard shortcuts and existing Studio Zoom in/Fit city worked.
- Physical Lab shortcut opened the dedicated showcase. Before capture, Dashboard indicated unknown demand and offered snapshot capture rather than planning. Explicit TEST preview/capture then plan/playback produced two trips, four completed, zero unserved, 6.13 modeled km, 36.4 virtual minutes, ₹171 rounded plan cost and ₹146 rounded modeled savings against serving all ten. All six low-fill virtual bins remained ineligible. [TEST results view](../build/dashboard-review/after-showcase-TEST.png).
- No saved browser city or calibration was changed by the browser walkthrough. Updated Dashboard left open on the guided demo for visual approval.
